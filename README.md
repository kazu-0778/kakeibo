# 家計簿アプリ セットアップ手順

## フォルダ構成

```
kakeibo/
├── index.html            画面
├── css/style.css         見た目
├── js/app.js             アプリ本体
├── js/db.js              データベースとのやり取り
├── js/config.js          Supabase の接続情報
├── vendor/               ライブラリ（Supabase・グラフ）
├── icons/                アプリアイコン
├── manifest.webmanifest  ホーム画面追加用
├── sw.js                 オフライン対応
└── supabase/schema.sql   データベース定義（Supabase で1回だけ実行）
```

---

## ステップ A：データベースを作る（1回だけ）

1. Supabase のプロジェクト画面で、左メニューの **SQL Editor** を開く
2. `supabase/schema.sql` の中身を**全部コピーして貼り付け**、右下の **Run** を押す
3. 「Success. No rows returned」と出れば完了

> 何度実行しても既存データは消えません。

## ステップ B：ログイン用アカウントを作る

1. 左メニュー **Authentication → Users** を開く
2. 右上 **Add user → Create new user**
3. メールアドレスとパスワードを入力し、**Auto Confirm User にチェック**を入れて **Create user**

### 他人が勝手に登録できないようにする（推奨）
1. **Authentication → Sign In / Providers**（画面によっては **Settings**）を開く
2. **Allow new users to sign up** を **オフ** にして保存

> 家族を追加するときは、ここで家族用のユーザーを作成してから共有設定をします（将来機能）。

## ステップ C：インターネットに公開する（GitHub Pages・無料）

1. https://github.com にログインし、右上 **＋ → New repository**
   - Repository name：`kakeibo`
   - **Public** を選択（無料プランで公開するため）
   - **Create repository**
2. 作成直後の画面で **「uploading an existing file」** をクリック
3. `kakeibo` フォルダの**中身すべて**（index.html や css フォルダなど）をドラッグ＆ドロップし、**Commit changes**
4. リポジトリの **Settings → Pages** を開き、
   - Source：**Deploy from a branch**
   - Branch：**main** / **/(root)** → **Save**
5. 1〜2分後、同じ画面に `https://＜あなたのID＞.github.io/kakeibo/` が表示されます

> リポジトリには公開用キー（Publishable key）が含まれますが、問題ありません。
> データベース側で「ログインした本人の世帯のデータしか読めない」制限をかけています。

## ステップ D：スマホのホーム画面に追加

- **iPhone（Safari）**：URL を開く → 共有ボタン（□↑）→ **ホーム画面に追加**
- **Android（Chrome）**：URL を開く → 右上︙ → **ホーム画面に追加**（または「アプリをインストール」）

## 使い方メモ

| やりたいこと | 操作 |
|---|---|
| 支出・収入の記録 | 入力タブで 金額 → カテゴリ → 「記録する」 |
| 日付を変える | 📅 をタップ → カレンダーから選択（「昨日」ボタンもあり） |
| 記録の修正・削除 | 入力タブの「最近の入力」や履歴タブで行をタップ |
| 固定費の登録 | 設定 → 固定費・定期収入 → ＋追加 |
| 変動する固定費の確定 | 「🔔 確認待ち」をタップ → 金額を入れて「確定」 |
| カテゴリの追加・編集 | 設定 → カテゴリ → ＋追加 / 行をタップ（▲▼で並べ替え） |

### 固定費の仕組み
- アプリを開いたときに、期日が来た固定費が自動で記録されます
- **固定**：設定した金額で確定として記録
- **変動（確認あり）**：予定金額で「確認待ち」として記録 → 実際の金額を入れて確定（確定までグラフに含まれません）
- 頻度は 毎月 / 2か月ごと / 3か月ごと / 半年ごと / 毎年。日付で「月末」を選ぶと月の長さに合わせます
- 何日もアプリを開かなかった場合も、開いたときにまとめて記録されます（二重登録はされません）

### 注意
- Supabase 無料プランは **1週間アクセスがないと一時停止** します。管理画面から再開できます（データは消えません）
- アプリを更新したら `sw.js` の `VERSION` を変えると、スマホにも確実に反映されます
