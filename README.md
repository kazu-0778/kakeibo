# 家計簿アプリ

スマホだけで完結する家計簿です（PWA）。データはすべてスマホの中（ブラウザ内のデータベース）に保存され、通信なしで動きます。

公開URL：https://kazu-0778.github.io/kakeibo/

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 見た目 |
| app.js | アプリ本体（入力・履歴・グラフ・設定） |
| db.js | データの保存（スマホ内のデータベース） |
| backup.js | CSVでのバックアップ・復元 |
| chart.umd.min.js | グラフ用ライブラリ（グラフ画面を開いたときだけ読み込む） |
| sw.js | オフライン対応・高速起動 |
| manifest.webmanifest, icon-*.png | ホーム画面に追加するための設定・アイコン |
| migrate.js, supabase.js, config.js, schema.sql | 【一時的】以前の保存先（Supabase）からの引き継ぎ用。引き継ぎ完了後に削除 |

## 使い方のポイント

- 入力は必ず **ホーム画面のアイコン** から行う（ブラウザで開いたページとはデータが別になる）
- **設定 → データ・バックアップ** から、CSVでバックアップ・復元ができる
- 前回のバックアップから3か月たつと、入力画面にお知らせが出る
- 機種変更のときは「旧スマホでバックアップを保存 → 新スマホで復元」

## 更新するとき

`sw.js` の `VERSION` を変更する。スマホでは、アプリを開き直すと裏で新しい版を取得し、次に開いたときに切り替わる。
